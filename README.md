# BookMarkSync

**简体中文** | [English](README.en.md) · [下载扩展](https://github.com/yishipi/BookMarkSync/releases/latest)

在同一台电脑上，让 Chrome 和 Edge 的书签保持一致。两边安装扩展，选择同一个本地文件夹，就能同步书签的新增、修改、移动、排序和删除。

书签通过本地文件交换，无需同步账号或额外程序，扩展本身不上传数据。

## 安装

1. 从 [Releases](https://github.com/yishipi/BookMarkSync/releases/latest) 下载 `BookMarkSync-extension-版本号.zip`，解压到一个固定位置，并保留这个文件夹。
2. 分别打开 Chrome 的 `chrome://extensions/` 和 Edge 的 `edge://extensions/`。开启**开发者模式**，点击**加载已解压的扩展程序**，选择包含 `manifest.json` 的解压目录。
3. 在两端打开 BookMarkSync，点击**选择目录**，选择同一个用来交换书签的本地文件夹，并允许读写。若弹窗提供**每次访问时都允许**，选择该项。
4. 检查合并预览，再分别点击**开始自动同步**。

从源码安装时，加载仓库中的 `extension` 文件夹。

## 平时怎么用

- 设置页可以关闭。编辑书签后会自动同步，默认每 30 秒检查一次另一端；电脑休眠或浏览器调度可能让检查延后。
- 首次合并会保留两边已有的书签。之后，**删除也会同步到另一端**。
- 误删或修改冲突时，可以先查看**恢复记录**。同步应用前会自动备份，共享目录的 `backups` 文件夹保留每端最近 10 份。
- 更新扩展时，用新文件替换原目录中的扩展文件，再到扩展管理页点击**重新加载**。

## 重开浏览器后不再同步？

1. 显示**需要目录授权**时，点击**恢复目录授权**，在浏览器弹窗中选择**每次访问时都允许**（若提供）。
2. 若仍处于暂停或等待开始状态，点击**恢复自动同步**；从未成功同步过时，按钮显示为**开始自动同步**。
3. 确认顶部显示**自动同步中**，并检查**最近同步**时间是否更新。若目录记录已被清除，需要重新选择原共享目录。

**立即同步**只执行一次，不会开启自动同步。Chrome 和 Edge 的目录授权需要分别处理，授权失效后需要你手动恢复。

## 使用前了解

- 只同步书签。密码、Cookie 和网站登录状态不会同步。
- 浏览器自带的云同步可以继续使用，也仍会按原设置上传、下载书签。
- 打开收藏夹下拉菜单或侧边面板不一定立即触发检查，后台仍会按间隔同步。企业管理的只读书签不会修改。
- 安装时可能看到“读取浏览记录”的权限提示：标签页权限用于识别书签管理器，扩展不记录浏览历史，也不读取网页内容。
